# Synthetic financial-file fixtures

This directory contains only deterministic synthetic fixtures used by Talli's
unit, integration, backup, and end-to-end tests. The routing, account, IBAN-like,
payee, memo, date, and amount values are examples and do not represent a real
person or financial account.

Never replace these files with a real statement. New fixtures must be generated
or hand-authored synthetic data and must not contain credentials, personally
identifying information, or real financial records.

Historical V5 design material is in
[`../history/v5-financial-file-import/`](../history/v5-financial-file-import/).
